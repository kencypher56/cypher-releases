## What was verified

- Every file above matches the SHA-256 GitHub reports for it (local copies in cypher-releases/dist were hashed one by one).
- Windows: the seven `-Setup-` EXEs are Inno Setup 6.5 installers (machine-wide, x64, Windows 10+). CV and Printers are electron-builder portable EXEs (x64), which install nothing. **None of the EXEs is Authenticode-signed.** WinGet and Chocolatey take unsigned files, but Windows' malware and SmartScreen checks may flag them during review.
- Silent switches, from the Inno Setup documentation: install `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-`, uninstall `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`. WinGet supplies them itself for `InstallerType: inno`.
- If the app is already running, the installers show a "close it and continue?" box through `MsgBox`. Inno only suppresses `SuppressibleMsgBox`, so a silent upgrade while the app is open stops at that question.
- The WinGet manifests leave out ProductCode: innoextract 1.9 cannot read Inno 6.5 installers, and the build scripts disagree on the Expenses AppId, so it could not be confirmed.
- Android: every APK passes `apksigner verify` (v2, plus v1 for Expenses). No store here needs an AAB. Target API is 33 to 34, and every APK with native code includes arm64-v8a. Not test-installed: no emulator or phone was connected.
- WinGet: 24 files validate against the official 1.12.0 schemas. Chocolatey: 8 nuspecs parse; `choco pack` runs in CI.
