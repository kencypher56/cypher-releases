## What was verified

- The website's phone screenshot `img/shots/phone/cypher-music-playlists.png` is completely blank (white). It was left out of every store upload; the site still shows it on the Cypher Music page.

- Every file above matches the SHA-256 GitHub reports for it (local copies in cypher-releases/dist were hashed one by one).
- Windows: the eight `-Setup-` EXEs are Inno Setup installers (machine-wide, x64, Windows 10+). CV and Printers are electron-builder portable EXEs (x64), which install nothing. **None of the EXEs is Authenticode-signed.** WinGet and Chocolatey take unsigned files, but Windows' malware and SmartScreen checks may flag them during review.
- Cypher CV and Cypher Printers: their READMEs say the Windows builds were tested only under Wine. They are submitted with everything else, as asked; a failure in WinGet's install test would show on their pull requests.
- Silent switches, from the Inno Setup documentation: install `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-`, uninstall `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`. WinGet supplies them itself for `InstallerType: inno`.
- If the app is already running, the installers show a "close it and continue?" box through `MsgBox`. Inno only suppresses `SuppressibleMsgBox`, so a silent upgrade while the app is open stops at that question.
- The WinGet manifests leave out ProductCode: innoextract 1.9 cannot read Inno 6.5 installers, and the build scripts disagree on the Expenses AppId, so it could not be confirmed.
- Android: every APK passes `apksigner verify` (v2, plus v1 for Expenses and BOT). No store here needs an AAB. Target API is 33 to 34, and every APK with native code includes arm64-v8a. Not test-installed: no emulator or phone was connected.
- WinGet: 27 files (9 apps) validate against the official 1.12.0 schemas. Chocolatey: 9 nuspecs parse; `choco pack` runs in CI.
- The release notes now say "The official sources for this software are Cypher Store and the store listings it links to" (changed on GitHub on 2026-11-25).
